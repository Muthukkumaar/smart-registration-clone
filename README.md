# Registration Form Project 🚀

A modern, responsive registration form built with **HTML, CSS (Tailwind), and JavaScript**. It features real-time validation, a live bio character counter, password strength feedback, and dynamic submit button control.

Website Link: https://muthukkumaar.github.io/smart-registration-clone/

## ✨ Key Features
- **Real-Time Validation:** Instant feedback on Name, Email, Password, and Bio fields as you type.
- **Live Character Counter:** Tracks bio length dynamically in the `"X / 200 characters"` format.
- **Password Strength & Toggle:** Enforces a minimum 6-character length with a show/hide password toggle.
- **Smart Submit Button:** Stays disabled until all four required fields are completely filled and valid.
- **Success State:** Displays a clean confirmation banner on successful submission.

## 📂 Quick Start
Simply download or clone the repository and open `index.html` in any modern web browser to test!
